# Portfólio — Lucas Kaoru

Sou estudante de **Engenharia de Software na FIAP** e técnico em **Desenvolvimento de Sistemas pela ETEC Paulista**. Estou construindo minha trajetória em desenvolvimento de software, com foco principal em **Back-end com Node.js, Express, APIs REST e MySQL**, além de experiência prática em projetos Full Stack.

Gosto de entender como as aplicações funcionam por trás da interface: rotas, autenticação, regras de negócio, organização do código e persistência de dados. Desenvolvo projetos acadêmicos e pessoais para transformar estudo em prática e evoluir minha capacidade de resolver problemas.

Atualmente, busco uma oportunidade de **estágio em desenvolvimento de software**, preferencialmente na área de Back-end.

## Projetos

### [TaskFlow — Gerenciador Kanban de tarefas](https://github.com/lucasknohara/taskflow)
Projeto pessoal Full Stack criado para organizar tarefas da faculdade e do dia a dia. Possui autenticação JWT, rotas protegidas e operações CRUD para gerenciamento de quadros e colunas, com API integrada ao MySQL.

**Tecnologias:** React, JavaScript, Node.js, Express, MySQL e JWT.

### [RedePratos — Plataforma de doação de alimentos](https://github.com/lucasknohara/RedePratos)
Projeto acadêmico desenvolvido em equipe no contexto da Global Solution da FIAP. Conecta doadores de alimentos a instituições sociais, organizando cadastro de alimentos, publicação de doações, solicitações e acompanhamento da entrega. O front-end está publicado na Vercel.

### [Biblioteca API](https://github.com/lucasknohara/Biblioteca)
Projeto pessoal para consulta de livros e controle de empréstimos e devoluções. Prática de validação de regras de negócio, modelagem relacional, separação de responsabilidades e operações com transações.

**Tecnologias:** Node.js, Express e MySQL.

### [PINGO — Sistema de aluguel de quadras](https://github.com/lucasknohara/PINGO)
Projeto acadêmico com API REST para gerenciamento de quadras e agendamentos, organização em rotas, controllers e models, integração com MySQL e integração com API externa de pagamento e tratamento das respostas do fluxo de QR Code.

**Tecnologias:** Node.js, Express e MySQL.

### [EcoTrend — E-commerce de ecobags](https://github.com/lucasknohara/Ecomerce)
Projeto acadêmico de Front-end com catálogo, filtros por categoria e preço, carrinho persistido no navegador e checkout com validações.

**Tecnologias:** React, JavaScript, Vite e localStorage.

### [StudyLens / SEP](https://sep-rose.vercel.app/)
Protótipo web acadêmico com telas responsivas para apresentar uma proposta de melhoria da segurança escolar e persistência local. O [código-fonte está no GitHub](https://github.com/lucasknohara/SEP).

**Tecnologias:** React, JavaScript e localStorage.

## Executar localmente

O portfólio é um site estático desenvolvido com HTML, CSS e JavaScript, sem framework de interface.

1. Clone ou baixe este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou utilize a extensão Live Server.

## Publicar com GitHub Pages

1. Envie os arquivos para a raiz do repositório que será publicado.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
